# SEO Jiyeon — Digital Business Card

26.09.04 수업 노트의 아이디어를 구현한 디지털 명함 웹페이지.

> **화면 전체가 흰 종이다.** 빈 화면에서 드래그로 마스킹 영역을 정하면 그 크기에
> 맞춰 텍스트가 드러나고, 그 자리를 탭하면 사각형이 들렸다가 아래로 떨어지면서
> 구멍이 뚫린다. 구멍으로 카메라가 보이고, 텍스트만 흰색으로 남는다.

```
index.html      구조
style.css       16 × 12 그리드 · 슬롯 배치 · 타이포 · 펀칭 애니메이션
app.js          드로잉 인터랙션 · 실시간 조판 계산 · 구멍 열고 닫기 · 카메라
assets/sky.jpg  카메라를 못 쓸 때 구멍으로 보이는 임시 하늘 사진
```

## 노트 → 구현 대응표

| 노트 | 구현 |
|---|---|
| ① 한 지점을 터치해 다른 지점으로 끌고 가 사각형을 그림 | `pointerdown → pointermove → pointerup` 으로 드래그. 10px 미만 이동은 탭으로 간주 |
| ② 그려진 사각형의 너비·비율에 따라 실시간 계산 | 그리드 한 칸 `unit = min(w/16, h/12)` 을 기준으로 `--name` / `--meta` 를 재계산. 너비와 비율이 동시에 반영됨 |
| ③ 각 정보를 터치하면 contact | 이메일 `mailto:`, 전화번호 `tel:` (2개 각각). 뚫기 전(검정)·뚫은 후(흰색) 양쪽 모두 동작 |
| ④ 사각형을 탭 → 펀칭 | 그 사각형이 살짝 들렸다가 회전하며 아래로 떨어지고, 자리에 구멍이 남는다 |
| ⑤ 새로 사각형을 그리면 | 열려 있던 구멍이 사각형 그대로 중심을 향해 좁아지며 닫힌다 |
| ⑥ 기본 화면에는 아무것도 없음 | 흰 종이만 있고, 사각형을 그려야 그 크기에 맞춰 텍스트가 드러난다 |
| ★ 카메라 허용하지 않는 경우는? ⇒ 임시 하늘 사진 | 구멍으로 카메라가 보이고, 못 쓰면 `assets/sky.jpg` 가 그 자리에 보인다 |
| 16 × 12 Grid | 모든 슬롯이 16열 12행 좌표에 배치. 드래그 중 그리드가 보이고 `GRID` 로 고정 표시 |
| margin 은 없음 | 슬롯이 사각형 모서리에 붙음 (padding 0) |
| 줄바꿈 우선, 줄임표는 최후 | 폭이 모자라면 먼저 줄바꿈한다. 슬롯의 행 밴드 안에 들어가는 줄 수(`--lines`)까지 쓰고, 그래도 모자랄 때에만 마지막 줄에 줄임표(…)가 붙는다. 이메일은 `@` 뒤에서 우선 끊는다 |
| 그룹 사이 1행 여백 | r3·r8 은 항상 비운다 → 상단(r0-2) · 이름(r4-7) · 하단(r9-11) |
| 정보 누락 방지 → 이름은 있어야 함 | 이름은 가로폭에 맞춰 크기를 별도로 캡. `unit < 4` 인 극소 구간에서만 다른 정보를 접고 이름만 남김 |
| 가운데 2열은 비움 | Director · Busan, Paris · 이메일 · 전화번호는 각각 최대 7열. c7·c8 은 항상 여백 |

### 구멍이 동작하는 방식

구멍을 그리는 대신, **흰 종이를 네 장으로 나눠 구멍 둘레만 채운다.**

| 요소 | 역할 |
|---|---|
| `.backdrop` | 카메라(없으면 하늘). 늘 맨 아래에 깔려 있고 구멍으로만 보인다 |
| `#sheet` 의 `.panel` × 4 | 구멍의 위·아래·좌·우를 채우는 흰 판. 판을 움직이면 구멍이 사각형 그대로 열리고 닫힌다 |
| `#flap` | 뚫려 나가는 조각. 흰 면 + 검정 텍스트. `punch-fall` 키프레임으로 들렸다가 떨어진다 |
| `#hole-text` | 구멍 안에 남는 흰 텍스트. 같은 자리·같은 내용 |

뚫을 때는 구멍이 **즉시** 열리고 조각이 그 위를 덮은 채 떨어지므로, 조각이 비켜나는 만큼
구멍이 드러난다. 닫을 때는 반대로 판이 `--close` 시간 동안 중심으로 모인다.
보이는 쪽 텍스트만 조작을 받도록 `inert` 로 두 층을 번갈아 켠다.

## 명함 배치 (16 × 12)

가운데 2열(c7·c8)은 이름을 제외한 모든 항목에서 비워 둔다.

가운데 2열(c7·c8)과 여백 행(r3·r8)은 이름을 제외하고 항상 비워 둔다.
각 밴드는 3행이므로, 폭이 모자라면 그 안에서 줄바꿈한다.

```
c0                    c7 c9                   c16
┌──────────────────────┬─┬──────────────────────┐ r0
│ DIRECTOR             │ │        BUSAN, PARIS  │ r0–r2
├ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┼─┼─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┤ r3   여백
│              SEO Jiyeon                       │ r4–r7
├ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┼─┼─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┤ r8   여백
│ fishwaswater@        │ │    +82 10 5632 8631  │ r9–r11
│ gmail.com            │ │  +33 06 61 67 75 71  │
└──────────────────────┴─┴──────────────────────┘
```

## 실행

카메라(`getUserMedia`)는 **HTTPS 또는 localhost** 에서만 동작합니다.

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

배포: `main` 브랜치를 GitHub Pages 가 그대로 서빙합니다 → https://bagaebin.github.io/SEO-Jiyeon/

## 조작

| 동작 | 결과 |
|---|---|
| 드래그 | 마스킹 영역을 지정하고, 그 크기에 맞춘 텍스트가 드러남 (열려 있던 구멍은 닫힘) |
| 사각형 탭 | 조각이 떨어지며 구멍이 뚫림 / 한 번 더 탭하면 구멍이 좁아지며 닫힘 |
| 정보 탭 | 메일 / 전화 연결 |
| `GRID` | 16 × 12 그리드와 마스킹 영역 경계를 상시 표시 |
| `RESET` | 표준 명함 비율(91:55)로 한 장 다시 놓음 |
