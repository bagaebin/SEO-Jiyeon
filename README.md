# SEO Jiyeon — Digital Business Card

26.09.04 수업 노트의 아이디어를 그대로 구현한 디지털 명함 웹페이지.

> **화면에 사각형을 그리면, 그 비율에 맞춰 실시간으로 조판되는 명함.**
> 배경은 실시간 카메라 화면이고, 명함의 각 정보는 누르면 바로 연결된다.

```
index.html   구조
style.css    16 × 12 그리드 · 슬롯 배치 · 타이포
app.js       드로잉 인터랙션 · 실시간 조판 계산 · 카메라
assets/sky.jpg  카메라 미허용 시 쓰이는 임시 하늘 사진
```

## 노트 → 구현 대응표

| 노트 | 구현 |
|---|---|
| ① 한 지점을 터치해 다른 지점으로 끌고 가 사각형을 그림 | `pointerdown → pointermove → pointerup` 으로 드래그 사각형 생성. 10px 미만 이동은 탭으로 간주 |
| ② 그려진 사각형의 너비·비율에 따라 실시간 계산 | 그리드 한 칸 `unit = min(w/16, h/12)` 을 기준으로 `--name` / `--meta` 크기를 매 프레임 재계산. 너비와 비율이 동시에 반영됨 |
| ③ 각 정보를 터치하면 contact | 이메일 `mailto:`, 전화번호 `tel:` — 탭하면 메일 앱 / 전화 앱으로 연결 |
| ★ 카메라 허용하지 않는 경우는? ⇒ 임시 하늘 사진 | `getUserMedia` 실패·거부 시 `assets/sky.jpg` 로 자동 대체. 하단 `카메라 켜기` 버튼으로 재시도 |
| 16 × 12 Grid | 모든 슬롯이 16열 12행 좌표에 배치됨. 드래그 중에는 그리드가 보이고, `GRID` 버튼으로 고정 표시 가능 |
| margin 은 없음 | 슬롯이 사각형 모서리에 붙음 (padding 0). 텍스트가 카드 경계에 그대로 맞닿음 |
| 줄임표(…) 사용 *(수정 반영)* | 슬롯 폭을 넘는 텍스트는 `text-overflow: ellipsis` 로 처리 |
| 정보 누락 방지 → 이름은 있어야 함 | 이름은 가로폭에 맞춰 크기를 별도로 캡. 사각형이 극단적으로 작아지는 구간(`unit < 4`)에서만 다른 정보를 접고 이름만 남김 |

## 정보 수정

`app.js` 상단의 `CONTACT` 한 곳만 고치면 됩니다. 현재 값은 **자리표시자**이므로 실제 이메일·전화번호로 교체하세요.

```js
const CONTACT = {
  name  : 'SEO Jiyeon',
  role  : 'Director',
  places: ['Busan', 'Paris'],
  email : 'hello@seojiyeon.studio',
  phone : { label: '+82 10 1234 5678', dial: '+821012345678' }
};
```

## 실행

카메라(`getUserMedia`)는 **HTTPS 또는 localhost** 에서만 동작합니다.

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

`file://` 로 열면 카메라가 차단되어 하늘 사진 배경으로 표시됩니다. GitHub Pages 등 HTTPS 호스팅에 올리면 실제 기기에서 후면 카메라가 켜집니다.
