# SEO Jiyeon — Digital Business Card

26.09.04 수업 노트의 아이디어를 구현한 디지털 명함 웹페이지.

> **화면 전체가 흰 종이다.** 빈 화면에서 드래그하면 그 영역이 안쪽 그림자로만 표시되고,
> 그 자리를 탭해야 사각형이 들렸다가 아래로 떨어지면서 구멍이 뚫린다.
> 그때 비로소 구멍 안에 텍스트가 흰색으로 드러난다.

페이지에는 명함 외의 요소가 없다. 제목도, 안내도, 버튼도 없다.

```
index.html      구조
style.css       16 × 12 그리드 · 슬롯 배치 · 타이포 · 펀칭 애니메이션
app.js          드로잉 인터랙션 · 실시간 조판 계산 · 구멍 열고 닫기 · 카메라
assets/sky.jpg  카메라를 못 쓸 때 구멍으로 보이는 임시 하늘 사진
```

## 노트 → 구현 대응표

| 노트 | 구현 |
|---|---|
| ① 한 지점을 터치해 다른 지점으로 끌고 가 사각형을 그림 | `pointerdown → pointermove → pointerup` 으로 드래그. 10px 미만 이동은 탭으로 간주. 그린 영역은 안쪽 그림자로만 표시되고 텍스트는 아직 없다 |
| ② 그려진 사각형의 너비·비율에 따라 실시간 계산 | 그리드 한 칸 `unit = min(w/16, h/12)` 을 기준으로 `--name` / `--meta` 를 재계산 |
| ③ 사각형을 탭 → 펀칭 | 조각이 살짝 들렸다가 회전하며 아래로 떨어지고, 구멍 안에 텍스트가 흰색으로 드러난다 |
| ④ 각 정보를 터치하면 contact | 이메일 `mailto:`, 전화번호 `tel:` (2개 각각). 뚫린 뒤에만 눌린다 |
| ⑤ 새로 사각형을 그리면 | 열려 있던 구멍이 사각형 그대로 중심을 향해 좁아지며 닫힌다 |
| ★ 카메라 허용하지 않는 경우는? ⇒ 임시 하늘 사진 | 구멍으로 카메라가 보이고, 못 쓰면 `assets/sky.jpg` 가 그 자리에 보인다 |
| 16 × 12 Grid | 모든 슬롯이 16열 12행 좌표에 배치 |
| margin 은 없음 | 슬롯이 사각형 모서리에 붙음 (padding 0) |
| 줄바꿈 우선, 줄임표는 최후 | 폭이 모자라면 먼저 줄바꿈한다. 슬롯의 행 밴드 안에 들어가는 줄 수(`--lines`)까지 쓰고, 최소 폰트 크기로도 넘치면 그때 줄임표(…) |
| 정보 누락 방지 → 이름은 있어야 함 | 사각형 최소 크기를 최소 폰트로 이름 한 줄이 들어가는 크기(120 × 76)로 두어, 아무리 작게 그려도 이름은 잘리지 않는다 |
| 가운데 2열은 비움 | Director · Busan, Paris · 이메일 · 전화번호는 각각 최대 7열. c7·c8 은 항상 여백 |
| 그룹 사이 1행 여백 | r3 · r8 은 항상 비운다 |

### 최소 크기

| | 값 | 이유 |
|---|---|---|
| `MIN_NAME` | 18px | 이름 가독성 하한 |
| `MIN_META` | 11px | 나머지 텍스트 가독성 하한 |
| `MIN_W × MIN_H` | 120 × 76 | 최소 폰트로도 이름 한 줄이 온전히 들어가는 크기 |

폰트는 사각형 크기에 따라 줄어들되 이 하한 아래로는 내려가지 않는다.
하한에 닿은 뒤에도 넘치면 줄바꿈하고, 밴드의 줄 수까지 모자라면 줄임표를 쓴다.
한 줄도 들어가지 않는 항목은 접는다(작은 사각형에서 전화번호가 먼저 접힌다).

### 구멍이 동작하는 방식

구멍을 그리는 대신, **흰 종이를 네 장으로 나눠 구멍 둘레만 채운다.**

| 요소 | 역할 |
|---|---|
| `.backdrop` | 카메라(없으면 하늘). 늘 맨 아래에 깔려 있고 구멍으로만 보인다 |
| `#sheet` 의 `.panel` × 4 | 구멍의 위·아래·좌·우를 채우는 흰 판. 판을 움직이면 구멍이 사각형 그대로 열리고 닫힌다 |
| `#flap` | 뚫려 나가는 빈 흰 조각. `punch-fall` 키프레임으로 들렸다가 떨어진다 |
| `#rim` | 그린 영역을 표시하는 안쪽 그림자. 뚫린 뒤에는 구멍의 두께가 된다. 조각 위·텍스트 아래에 둔다 |
| `#content` | 구멍 안에서만 드러나는 흰 텍스트 |

뚫을 때는 구멍이 **즉시** 열리고 조각이 그 위를 덮은 채 떨어지므로, 조각이 비켜나는 만큼
구멍이 드러난다. 닫을 때는 반대로 판이 `--close` 시간 동안 중심으로 모인다.

## 실행

카메라(`getUserMedia`)는 **HTTPS 또는 localhost** 에서만 동작합니다.
버튼을 없앴으므로, 처음에 권한을 거부한 경우 첫 조작에서 한 번 더 요청합니다.

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

배포: `main` 브랜치를 GitHub Pages 가 그대로 서빙합니다 → https://bagaebin.github.io/SEO-Jiyeon/
