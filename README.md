# SEO Jiyeon — Digital Business Card

26.09.04 수업 노트의 아이디어를 그대로 구현한 디지털 명함 웹페이지.

> **화면에 사각형을 그리면, 그 비율에 맞춰 실시간으로 조판되는 명함.**
> 명함을 한 번 더 누르면 흰 면이 펀칭되면서 뒤가 드러나고, 텍스트만 흰색으로 남는다.

```
index.html      구조
style.css       16 × 12 그리드 · 슬롯 배치 · 타이포 · 펀칭 마스크
app.js          드로잉 인터랙션 · 실시간 조판 계산 · 펀칭 · 카메라
assets/sky.jpg  카메라를 못 쓸 때 뚫린 자리에 드러나는 임시 하늘 사진
```

## 노트 → 구현 대응표

| 노트 | 구현 |
|---|---|
| ① 한 지점을 터치해 다른 지점으로 끌고 가 사각형을 그림 | `pointerdown → pointermove → pointerup` 으로 드래그 사각형 생성. 10px 미만 이동은 탭으로 간주 |
| ② 그려진 사각형의 너비·비율에 따라 실시간 계산 | 그리드 한 칸 `unit = min(w/16, h/12)` 을 기준으로 `--name` / `--meta` 크기를 재계산. 너비와 비율이 동시에 반영됨 |
| ③ 각 정보를 터치하면 contact | 이메일 `mailto:`, 전화번호 `tel:` (2개 각각) — 탭하면 메일 앱 / 전화 앱으로 연결 |
| ④ 사각형을 한 번 더 터치 → 펀칭 | 탭한 지점을 중심으로 흰 면에 원형 구멍이 뚫린다 |
| ★ 카메라 허용하지 않는 경우는? ⇒ 임시 하늘 사진 | 카메라가 있으면 뚫린 자리로 실제 배경(카메라)이 그대로 비치고, 없으면 `assets/sky.jpg` 가 그 자리에 드러난다 |
| 16 × 12 Grid | 모든 슬롯이 16열 12행 좌표에 배치됨. 드래그 중에는 그리드가 보이고, `GRID` 버튼으로 고정 표시 가능 |
| margin 은 없음 | 슬롯이 사각형 모서리에 붙음 (padding 0). 텍스트가 카드 경계에 그대로 맞닿음 |
| 줄임표(…) 사용 *(수정 반영)* | 슬롯 폭을 넘는 텍스트는 `text-overflow: ellipsis` 로 처리 |
| 정보 누락 방지 → 이름은 있어야 함 | 이름은 가로폭에 맞춰 크기를 별도로 캡. 사각형이 극단적으로 작아지는 구간(`unit < 4`)에서만 다른 정보를 접고 이름만 남김 |

### 펀칭이 동작하는 방식

흰 면을 다른 층으로 덮는 게 아니라 **실제로 뚫는다.**

| 층 | 역할 | 마스크 |
|---|---|---|
| `#sky` | 카메라가 없을 때 뚫린 자리에 드러날 하늘 (뷰포트에 고정된 것처럼 역보정) | — |
| `#paper` | 백색 단색 면 | 원 **바깥**만 남김 |
| `#content` | 검정 텍스트 · 실제 링크 | 원 **바깥**만 남김 |
| `#content-ghost` | 같은 자리의 흰 텍스트 사본 | 원 **안**만 남김 |

명함 자체는 배경이 없으므로, 카메라가 켜져 있으면 뚫린 자리로 **페이지 배경이 그대로 비친다.**
경계가 사라지고 흰 텍스트만 화면에 남는다. 반지름 `--r` 은 `@property` 로 등록해 트랜지션을 건다.

## 실행

카메라(`getUserMedia`)는 **HTTPS 또는 localhost** 에서만 동작합니다.

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

`file://` 로 열면 카메라가 차단되어, 펀칭했을 때 하늘 사진이 드러납니다.
GitHub Pages 등 HTTPS 호스팅에 올리면 실제 기기에서 후면 카메라가 켜집니다.

| `RESET` | 표준 명함 비율(91:55)로 복귀 |
